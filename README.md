# Hey Fae

A free static website that can be hosted with GitHub Pages.

## Customize

Edit these files:

- `index.html` for the words, sections, and links
- `styles.css` for colors, spacing, and layout
- `assets/hero-workspace.png` for the hero image

## Publish With GitHub Pages

1. Create a new repository on GitHub.
2. Push this folder to that repository.
3. In GitHub, open the repository settings.
4. Go to **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/root` folder, then save.

Your site will be available at:

```text
https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/
```

If the repository is named `YOUR-USERNAME.github.io`, the site will be available at:

```text
https://YOUR-USERNAME.github.io/
```
